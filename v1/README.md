# ORYNTH R/01

ORYNTH R/01 is a no-build, single-page fictional open-wheel concept showcase built with semantic HTML, custom CSS, and browser-native JavaScript. It uses exact pinned optional enhancements: GSAP/ScrollTrigger 3.12.5 and Three.js 0.164.1.

## Run locally (Windows / PowerShell)

From `D:\xampp\htdocs\nimbus\apex-racing`:

```powershell
& 'D:\xampp\php\php.exe' -S 127.0.0.1:8080 -t 'D:\xampp\htdocs\nimbus\apex-racing'
```

Open `http://127.0.0.1:8080/`. Stop the finite local session with `Ctrl+C`. The document also remains substantive when opened directly, though optional CDN modules require HTTP.

## Architecture

- `index.html` owns the complete semantic story, canonical concept data, permanent tyre comparison, disclosures, native links, and inline SVG fallback artwork.
- `css/styles.css` provides the responsive wind-tunnel-noir system, safe normal-flow defaults, class-gated desktop stories, focus/touch states, and CSS-first reduced-motion protection.
- `js/main.js` progressively adds the bounded intro, accessible mobile menu, tyre explorer, replay, document progress, pinned GSAP stories, and procedural Three.js vehicle through one reversible lifecycle.

## Fallback behavior

No content depends on JavaScript, GSAP, ScrollTrigger, Three.js, or WebGL. With JavaScript disabled, navigation and anchors remain native, all final values and tyre records remain visible, and authored SVG vehicle views remain in place. Reduced motion prevents motion dependencies from initializing. WebGL is shown only after guarded compilation and a first render; failures or context loss restore the side-profile SVG. The renderer uses capped DPR, bounded geometry/particles, no shadows or postprocessing, and pauses while relevant sections are offscreen or the document is hidden.

## Features

Eight responsive story sections cover design intent, staged velocity, aerodynamics, the fictional OV-6H hybrid system, tyre construction and three fictional modes, vehicle geometry, and a replayable finale.
